# autoloc-api

Atelier 1 (Séance 2) - Spring Boot + Maven + première entité JPA.

## Lancer
1. Démarrer MySQL (port 3306).
2. Définir le mot de passe (si root en a un) : variable d'environnement `DB_PASSWORD`.
3. Ouvrir le dossier dans IntelliJ (Open as Project), activer l'annotation processing (Lombok).
4. Lancer `AutolocApiApplication`.
5. Vérifier : `USE autoloc_db; SHOW TABLES;` -> 9 tables.
